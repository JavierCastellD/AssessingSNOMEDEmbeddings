# Probing Embedding Methods for Structural and Semantic Knowledge in SNOMED CT
This repository contains all the code developed for the article *Probing Embedding Methods for Structural and Semantic Knowledge in SNOMED CT*. The aim of this study is to evaluate the clinical properties encoded in embeddings through probing. More specifically, we focus on which SNOMED CT characteristics can be found on embeddings generated by different encoders. The scripts used to train the probe, as well as to generate the datasets for each task can be found here.


### Download SNOMED CT
To generate the datasets, train the models, or run the experiments, a copy of the SNOMED CT International Edition (release 20240101) is required. Use of SNOMED CT requires a license, which is free of charge in SNOMED International member countries and can be obtained through your national release centre or the [SNOMED International Member Licensing and Distribution Service](https://mlds.ihtsdotools.org/).

The embeddings used in the paper are available on Zenodo (see `embeddings/README.md`). They are numerical vectors indexed by SNOMED CT identifier.
